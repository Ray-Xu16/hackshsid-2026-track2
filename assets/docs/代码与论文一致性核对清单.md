## F. 数值影响（§4 表格需替换）

修正的全部是口径问题，但其中 N23（往返效率 81%→90%）、N26（弹性日总量固定）、N35（光伏限幅）会改变数值。旧代码已复现论文原表，新旧对比如下：

| Case | 电费（元/年）旧→新 | 碳（tCO₂e/年）旧→新 | 绿电消纳旧→新 |
|---|---|---|---|
| Relaxed lower bound | 705,676 → **747,449** | 982.3 → **1,040.4** | — |
| S0 无调度 | 1,802,696 → **1,839,581** | 1,771.2 → **1,801.1** | 93.9% → **96.2%** |
| Case A, λ=0.2 | 1,701,957 → **1,762,577** | 1,394.0 → **1,416.8** | 97.2% → **99.5%** |
| Case A, λ=1.0 | 1,085,901 → **1,069,314** | 2,229.6 → **2,197.3** | 80.3% → **84.4%** |
| Case B, 有噪预报 | 1,619,952 → **1,657,861** | 1,553.7 → **1,564.4** | 92.6% → **96.5%** |
| Case B, 完美预报 | 1,710,227 → **1,770,949** | 1,394.3 → **1,417.3** | 97.4% → **99.5%** |

派生百分比（正文里的三个数也要改）：
- 绿电优先：电费 **−5.6% → −4.2%**，碳 **−21.3% → −21.3%**（碳几乎没变）
- 成本优先：电费 **−39.8% → −41.9%**，碳 **+25.9% → +22.0%**
- 有噪预报：碳 **−12.3% → −13.1%**；"完美预报与 Case A 相差 0.5% 以内"仍成立（电费 +0.47%、碳 +0.04%）

变化归因（可复算）：
1. **储能效率口径（N23）** 单独贡献电费 −3.7 万元、碳 −38.3 t —— 单程从 0.9 改回 √0.9 后，同样的电量能多放出约 11%。
2. **光伏限幅（N35）** 使年绿电从 3,937 MWh 降到 3,779 MWh（−4.0%），多买约 158 MWh 网电，约 +9.8 万元 —— 这是电费上升的主要来源，也是"参数标称 800 kW 就该有 800 kW 上限"的代价。
3. **弹性日总量固定（N26）** 把随机 ±10% 的抖动去掉，年弹性电量 2,192 → 2,190 MWh，影响 <0.1%。
