### 1.5 项目灵感与说明

```
【我们怎么理解这个问题】
AI 数据中心的电费和碳排不是同一个变量。在我们的 8,760 小时仿真里，全年均价 0.617 元/kWh、
平均碳强度 573.5 gCO₂e/kWh；把 8,760 小时按价格排序，最便宜的 10%（876 小时）均价 0.290 元
但碳强度高达 639.9 g/kWh；按碳强度排序，最干净的 10% 是 423.9 g/kWh、均价却要 0.821 元。
两组小时没有任何一小时重叠，价格与碳强度的相关系数是 −0.22。
也就是说：省钱和减碳在这套系统里方向相反，任何"谷段充电就对了"的直觉都会加碳。
同时还有两个约束把空间压得更窄：可延迟的推理任务有截止窗口（SLA 不能破），
储能把午间余电搬到晚高峰时又要吃掉一成往返损耗、还不能把电放空。

【我们怎么解决】
1) 先造一个可复现的仿真台：TOU 四段电价 + AR(1) 扰动；分时碳强度（日内锚点 + 季节 + 噪声 + 校准）；
光伏用太阳高度角模型（北纬 24.5°，厦门）、风电用切入 3 / 额定 11 m/s 的功率曲线；
负载拆成刚性 4,375 MWh + 弹性 2,190 MWh（日总量固定、时段可挪），PUE 1.20，储能 2 MWh / 1 MW、
往返效率 0.90。全部参数集中在 config/params.py，逐项标注论文出处。
2) 把"什么时候干活"变成一个打分问题：每小时分数 = λ·归一化价格 + (1−λ)·归一化碳强度，
弹性任务按"最低分小时优先"装填，同时硬检查截止窗口——违反 SLA 的任务直接判失败，不做软惩罚糊过去。
3) 储能只管两件事：谷充峰放、绿电时移。单向效率取 √0.90、SOC 限制在 10%–100%、充放互斥，
放电量还预留到"当日分数更高的那些小时"，避免白天放空、晚上买贵电。
4) 多目标不拍脑袋：λ 从 1 扫到 0 得到成本—碳前沿，用非支配排序标出 front，再用 maximin 选一个
"两边都不吃亏"的折中点作为推荐方案。

【独特之处】
· 不给"接近最优"，给"能不能关掉的差距"。我们解析出一个松弛下界（残余负载 × 当日最低价/最低碳）：
  它要求把 2,786,526 kWh 塞进同一个小时，等于刚性峰值的 3,685 倍，储能只有需求的 0.07%——
  按构造不可达。实测差距里 91.8% 来自"价格高于最低"这一物理事实，结构上关不掉，
  所以我们报告的是"关闭率"而不是"接近最优"，避免自我评分失真。
· 配对情景，把因果锁死。三情景共用同一 seed，天气与负载逐字节相同，差异 100% 归因于情景参数；
  S1 与 S2 的弹性排布逐值相同（S2 只是把储能功率从 0 打开），所以 S2−S1 的差 100% 归因于储能。
· 零求解器、零黑箱，可审计。规则 + 贪心，193 项自检（能量守恒、绿电恒等式、SOC 边界、SLA、
  上下界序关系）+ 8 项契约测试；工程重构前后 9 份 CSV 与 4 张 PNG 逐字节一致（md5 相同）。

【结果】
· 基准情景，绿电优先 + 储能（λ=0.2）：碳 1,416.8 t（−21.3%）、电费 1,762,577 元（−4.2%）、
  绿电利用率 99.5%、SLA 100%、储能吞吐 636,969 kWh（占年负载 9.7%、318 次等效满循环）。
· 只做时间迁移、不开储能：碳 −15.3%，但要多付 7.9% 电费——证明"迁移必须配储能才划算"。
· 高电价情景 λ=0.3：电费 −18.5%、碳 −17.3%，是三个情景里最干净的"双赢"点。
· λ=1.0（只看钱）：电费 −41.9%，但碳 +22.0%——同一套代码，把权衡关系直接摆出来给评委看。
```
